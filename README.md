# SideTracked 🎮

> Turn getting sidetracked into progress.

SideTracked is a gamified ADHD task manager that turns everyday
chaos into quests, missions, rituals, boss encounters, and questionable
adventures.

## 🧰 Tech Stack

### Frontend
- Angular
- TypeScript

### Backend
- Java
- Spring Boot

### Database
- MySQL
